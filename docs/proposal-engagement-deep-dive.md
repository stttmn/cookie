# 深掘り版: 提案内容 × 顧客コミュニケーション/エンゲージメント強化

`ai-sales-playbook.md` のうち「提案の質」と「顧客との接点の質・量」に絞って、
**そのまま使えるプロンプト例**と**仕組みの設計**まで落とし込んだ版。

強い提案とエンゲージメントの本質は同じで、**「Googleの話」ではなく「顧客のビジネスの話」をすること**。
AIの役割は、顧客ごとにそれをやるための調査・翻訳・パーソナライズのコストをほぼゼロにすること。

---

# Part A. 提案内容の強化

## A-1. 課題仮説の質を上げる「仮説ジェネレーター」

提案が刺さらない最大の原因は、プロダクト起点(「PMaxを入れましょう」)で顧客課題起点になっていないこと。
Deep Research / NotebookLM で顧客情報を集めた上で、次のプロンプトを通す。

```
あなたはGoogle広告のシニア営業ストラテジストです。
以下の顧客情報を読み、この会社が今期直面しているビジネス課題の仮説を3つ立ててください。

各仮説について:
1. 根拠(顧客情報のどこから読み取ったか)
2. その課題をGoogle広告への投資で解決できるとしたらどういうロジックか
3. 商談で仮説を検証するための質問(Yes/Noで答えられない開かれた質問)

顧客情報:
- 会社: {会社名} / 業種: {業種}
- 決算・ニュースの要点: {Deep Researchの出力を貼る}
- 現在の広告運用状況: {月額予算、主要キャンペーン、KPI}
```

ポイント: **提案書を書き始める前に**これをやる。提案の骨子が「課題→解決」の順になる。

## A-2. 顧客の語彙・KPIで語る「翻訳レイヤー」

同じ提案でも、顧客が社内で使っている言葉に合わせるだけで通りやすさが変わる。
決算説明資料・中期経営計画・社長インタビューには、その会社の「公式の言葉」(重点戦略、KPIの呼び方)が載っている。

```
以下は{会社名}の決算説明資料の抜粋です。
この会社が社内で使っていそうな重要キーワード・KPI・戦略スローガンを抽出してください。

次に、私のGoogle広告提案の骨子を、それらの言葉を使って書き直してください。
例えば「コンバージョン増加」ではなく、この会社が使う「{例: 新規会員獲得}」という言葉で。

提案骨子: {自分の提案の箇条書き}
資料抜粋: {貼り付け}
```

決裁者向けの提案ほど効く。「広告の話」が「経営計画の実行手段の話」に変わる。

## A-3. 松竹梅の3案構成を自動生成する

増額提案は1案で出すと Yes/No の議論になる。3案で出すと「どれにするか」の議論になる。

```
以下の顧客に対する広告投資プランを3案作ってください。

- プランA(現状維持+効率化): 予算据え置き。{推奨プロダクト}導入で効率改善
- プランB(推奨): 予算+{X}%。インプレッションシェア損失の回収 + {推奨プロダクト}
- プランC(機会最大化): 予算+{Y}%。{新規プロダクト/新チャネル}への展開込み

各案に: 想定される成果レンジ / リスク / この案を選ぶべき会社の状況、を添えてください。
「プランBが合理的に見える」構成にしつつ、数字は以下の実績データと矛盾しないように。

実績データ: {Performance Planner / 過去実績}
```

注意: 数字は必ず Performance Planner 等の一次ソースで裏取りする。AIには**構成とストーリー**を作らせ、数字の根拠は自分が持つ。

## A-4. 提案書の「レッドチームGem」— 出す前に叩かれておく

Gemini の Gems に以下を仕込んだ「厳しい決裁者Gem」を作り、提案書を出す前に必ず通す。

```
【Gemの指示文】
あなたは広告予算に厳しい事業会社の役員です。営業からの提案書を以下の観点で容赦なくレビューしてください:
1. 「で、うちの売上はいくら増えるの?」に答えているか
2. Googleの都合(プロダクトを売りたい)に見える箇所はどこか
3. 数字の根拠が弱い箇所はどこか
4. 競合媒体(他のプラットフォーム)でも同じことができるのでは?と思う箇所
5. この提案を断る一番簡単な理由

最後に、指摘を反映した改善版のアウトラインを提示してください。
```

これを通すだけで提案書の弱点が事前に潰れる。チームで共有すれば提案品質の底上げになる。

## A-5. 実績データの「So What 変換」

レポートの数字を「意味」に変換する型。QBRやマンスリーレポートの冒頭に使う。

```
以下の広告パフォーマンスデータから、経営層向けのエグゼクティブサマリを作ってください。

構成:
1. 一言でいうと(What): 今月のビジネス成果を1文で
2. なぜそうなったか(Why): 主要因を2-3個、専門用語を使わずに
3. 見つかった機会(Opportunity): データが示す「取りこぼし」を金額感付きで
   ※特にインプレッションシェア損失(予算)があれば「機会損失額」として换算
4. 提案(Action): 来月やるべきこと。投資判断が必要なものは明示

データ: {Sheets/レポートを貼る}
禁止事項: CPA、ROASなどの略語を説明なしに使わない。
```

「IS損失(予算)→ 取りこぼし金額」の変換は増額提案の最強の弾。**機械的に毎月やる**価値がある。

## A-6. クリエイティブモックで「完成形を見せる」提案

- Imagen で顧客の商材に合わせた広告ビジュアル案を3-5パターン生成し、提案書に「イメージ」として貼る。
- Veo / Google Vids で15秒の動画広告モック。Demand Gen・動画キャンペーン提案の説得力が段違いになる。
- プロンプトのコツ: 顧客の実際の商品写真の特徴・ブランドトーン(サイトから読み取れる)を言語化してから生成する。

```
{会社名}のWebサイトの特徴: {トーン、色、ターゲット層}
この世界観に合う、{商品}のディスプレイ広告用ビジュアルのコンセプトを5案。
各案: ビジュアル説明 / キャッチコピー / 想定オーディエンス
→ 気に入った案をImagenで画像化
```

効果は二重: 提案が具体的になる + 「制作リソースがない」という導入障壁が消える。

## A-7. 役職別の書き分け

同じ提案を、送る相手ごとに1分で書き分ける。

```
この提案サマリを3バージョンに書き分けてください:
- 経営者向け: 3行。投資対効果と経営戦略との接続のみ
- マーケ責任者向け: 半ページ。戦略ロジックと競合文脈
- 運用担当者向け: 具体的な設定変更内容と工数、移行手順
提案サマリ: {...}
```

# Part B. コミュニケーション・エンゲージメント強化

## B-1. 【本命】エンゲージメント・エンジン: 「連絡する理由」を自動供給する

エンゲージメントが途切れる理由は「連絡するネタがない」こと。逆に言えば、**顧客ごとの"話しかける理由"を毎週自動で供給する仕組み**があれば、接点の量と質が同時に上がる。

3系統のシグナルをGASで毎週収集し、Gemini APIでタッチポイント(連絡文面)まで生成する:

| シグナル源 | 検知するもの | 生成されるタッチポイント例 |
|---|---|---|
| ① ニュース(Gemini + Search grounding) | 新商品、出店、キャンペーン、決算、人事 | 「新商品○○の発売を拝見しました。発売期の検索需要を確実に捕捉するため…」 |
| ② パフォーマンス(Ads Scripts) | CV急増/急減、IS損失拡大、予算消化率 | 「今週CVが+30%でした。この勢いのうちに予算上限を…」 |
| ③ 市場・季節(Google Trends / 業界カレンダー) | 需要期の接近、検索トレンド変化 | 「例年○月に検索需要が1.8倍になります。準備のご相談を…」 |

アーキテクチャ(全てGoogle内で完結):

```
[Sheets: 顧客マスタ]──┐
[Ads Scripts→Sheets]──┼→ [GAS 週次トリガー] → [Gemini API] → [Gmail下書き] + [Chat/メールでダイジェスト通知]
[Trends/ニュース]────┘
```

運用: 月曜朝に「今週の推奨タッチポイント一覧(顧客名/理由/下書きリンク)」が届く → 自分は確認して送るだけ。
**送信は必ず人間が行う**(下書きまでが自動化の範囲)。

## B-2. パーソナライズメール工場(質を落とさず量を増やす)

一斉配信テンプレは開封されない。1通ずつ書くと時間がない。その中間を取る。

```
【GAS + Gemini APIで顧客リストを1行ずつ処理するプロンプト】
以下の顧客に送る営業メールを書いてください。

ルール:
- 件名は「相手のビジネスの言葉」で。Googleのプロダクト名を件名に入れない
- 冒頭は必ずその会社固有の話題(ニュース/実績/前回の会話)から
- 本文は5文以内。CTAは1つだけ(15分の電話 or 資料への反応)
- 敬語は丁寧だが、堅すぎない。絵文字なし

顧客情報: {社名/担当者/業種/直近の話題/前回接点のメモ/提案したいこと}
```

生成結果は GmailApp.createDraft() で下書き保存。10社分のメールが「各社専用の内容」で数分で用意できる。

## B-3. 商談後60分フォローの型

商談直後のフォローが速く・具体的なほどエンゲージメントは維持される。

フロー: Gemini in Meet の自動メモ → GASが議事録Docsを取得 → Gemini APIで以下を生成 → Gmail下書き:

```
この商談議事録から、フォローアップメールを作ってください。
構成:
1. お礼(1文)
2. 本日の決定事項(箇条書き、相手の発言の言葉を使う)
3. 私のネクストアクションと期日
4. 相手にお願いした宿題(あれば、柔らかく)
5. 次回日程の確認
また、議事録から「相手が関心を示したが今日は深掘りしなかったトピック」を抽出し、
次回商談の提案テーマとして私向けにメモしてください。
```

最後の「拾い残しトピック抽出」が次の商談の質を上げる隠し味。

## B-4. 売り込まない接点: 月次インサイトレター

毎回売り込みだと接点が痩せる。「顧客の業界の話」だけをする月次コンテンツを挟む。

- Google Trends + 検索データ + 業界ニュースをGeminiでまとめ、「{業界}デジタルマーケの今月の3トピック」を顧客別業種ごとに生成。
- 1業種分作れば同業種の顧客全員に使える(冒頭の1段落だけ各社向けに差し替え)。
- NotebookLM の音声概要にして「10分のポッドキャスト」として送る手も。忙しい決裁者に意外と刺さる。
- これ自体が「Googleはデータを持っている」という無言のブランディングになる。

## B-5. 休眠・沈黙顧客の再活性化

GASで「最終接点から45日以上経過」の顧客を検知し、再エンゲージ文面を生成:

```
この顧客とは{N}日接点がありません。最後の会話は「{最終議事録の要約}」でした。
気まずくならず、相手にメリットのある再連絡メールを3パターン作ってください:
A. 業界ニュースをきっかけにする
B. アカウントのパフォーマンスデータから見つけた機会をきっかけにする
C. 新機能・新プロダクトの案内をきっかけにする
「ご無沙汰しております、その後いかがでしょうか」のような中身のない文面は禁止。
```

「中身のない文面禁止」の一行が生成品質を大きく変える。

## B-6. エンゲージメント健全性のスコアリング

Sheetsのパイプライン+Gmailのスレッド情報(最終返信日、返信間隔、返信の長さの変化)をGASで集計し、Geminiに温度感を診断させる:

```
各顧客のコミュニケーション履歴サマリから、エンゲージメント健全性を高/中/低で判定し、
「低」の顧客には考えられる原因と、次に取るべきアクションを1つずつ提案してください。
```

パイプラインレビューの前に回すと、感覚ではなくデータでフォロー優先度を決められる。

## B-7. 顧客に「渡す」AI体験

コミュニケーションの受け手にAIを体験させる:

- **NotebookLM ノートブックの共有**: 提案書・レポート・関連ヘルプ記事をノートブックにまとめて共有。顧客は自分のペースで質問しながら理解できる。「提案書PDF添付」よりエンゲージメントの質が上がる。
- **音声概要を予習資料に**: 商談前に「10分で分かる今回のご提案」を音声で送る。
- **Google Vids のパーソナライズ動画**: 四半期レビューの冒頭サマリを動画メッセージで。
- これら全てが「GoogleのAIすごい」体験= AI系広告プロダクト(PMax、AI生成アセット)への信頼の土台になる。

# Part C. どれから作るか(実装ロードマップ案)

| 週 | やること | 種別 |
|---|---|---|
| 今日 | A-4 レッドチームGem、A-1 仮説ジェネレーター(プロンプトをGems登録) | ノーコード |
| 1週目 | B-2 パーソナライズメール工場(GAS + Sheets + Gemini API + Gmail下書き) | コード小 |
| 2週目 | B-3 商談後フォロー自動ドラフト(Meet議事録 → Gmail下書き) | コード小 |
| 3-4週目 | B-1 エンゲージメント・エンジン(シグナル収集 → タッチポイント生成) | コード中 |
| 継続 | A-5 So What変換をレポート運用に組み込み / B-4 月次レター | 運用 |

B-2 → B-3 → B-1 の順で作ると、B-1 は B-2 の生成部品を再利用できるので開発が楽。
