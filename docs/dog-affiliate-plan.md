# 犬アフィリエイトで月10万円を稼ぐ実行計画

作成日: 2026-07-06

## 1. 結論（戦略の骨子）

**「高単価案件 × SNSで集客 × ブログ/LPで成約」の組み合わせで、月25〜35件の成約を作る。**

月10万円は「単価 × 件数」の掛け算でしか達成できない。低単価（Amazon・楽天の料率2〜4%）だけで狙うと月250万円分の売上紹介が必要になり非現実的。高単価案件を軸に据える。

| 収益源 | 単価目安 | 月間目標件数 | 月間収益 |
| --- | --- | --- | --- |
| ドッグフードD2C（モグワン等） | 3,000〜5,000円/件 | 15件 | 約60,000円 |
| ペット保険（資料請求・見積もり） | 1,000〜5,000円/件 | 10件 | 約25,000円 |
| しつけ教材・ペット用品サブスク | 2,000〜10,000円/件 | 3件 | 約10,000円 |
| Amazon・楽天（首輪・おもちゃ等の物販） | 売上の2〜4% | 多数 | 約5,000円 |
| **合計** | | | **約100,000円** |

## 2. 案件選定（何を売るか）

### 主力: ドッグフードD2C（単価3,000〜5,000円）
- ペット系の広告単価は平均3,000円程度、高いものは5,000円超。
- 代表例: モグワン、カナガン、このこのごはん、ブッチ、うまか 等。
- **同じ案件でもASPによって単価が違う**（例: カナガンは A8.net 2,400円 vs afb 3,690円）。必ず複数ASPに登録して比較する。
- 登録すべきASP: **A8.net / afb / もしもアフィリエイト / バリューコマース / アクセストレード**（すべて無料）。

### 準主力: ペット保険（単価1,000〜5,000円）
- 「資料請求」「一括見積もり」成果なので購入案件よりハードルが低く、CVRが高い。
- 「ペット保険 比較」「犬 医療費 いくら」系のキーワードで狙う。
- 保険スクエアbang! 等の比較系案件は afb / A8.net の両方にあり、条件を比較する。

### 補助: 物販・サブスク
- Amazonアソシエイト・楽天アフィリエイトは単価が低いが承認率が高く、「ついで買い」で積み上がる。レビュー記事の取りこぼし防止に貼る。
- ペットカメラ、犬の歯磨きサブスク、オーダーメイド首輪などの中単価案件も随時追加。

## 3. 集客チャネル（どう人を集めるか）

2026年現在、新規ドメインのSEO一本足打法は AI Overview とアップデートの影響で立ち上がりが遅い。**SNSを起点に、ブログを成約装置にする二段構え**が現実的。

### ① Instagram / TikTok（メイン集客）
- 愛犬アカウントを開設し、リール/ショート動画を **週4〜5本** 投稿。
- 伸びるテーマ: 「犬種あるある」「フード切り替えのビフォーアフター」「動物病院で言われたこと」「しつけの失敗談」。
- プロフィールのリンクからブログの比較記事へ誘導。Instagramは1万フォロワー未満でもストーリーズのリンクが使える。
- 自分の犬がいない場合: 家族・友人の犬の撮影協力、保護犬ボランティア参加、イラスト・解説系アカウントでも可。

### ② ブログ（成約装置 + 中長期SEO）
- WordPress（独自ドメイン）で開設。初期費用は年1.5万円程度。
- 記事構成の型:
  - **収益記事（2割）**: 「〇〇（フード名） 口コミ」「ペット保険 比較 トイプードル」「子犬 ドッグフード おすすめ」
  - **集客記事（8割）**: 「犬 ご飯食べない 対処」「トイプードル 抜け毛 時期」「犬 留守番 何時間」→ 記事内から収益記事へ内部リンク。
- **犬種特化**（例: トイプードル専門、柴犬専門）にすると競合の総合サイトと戦わずに済み、E-E-A-T的にも一貫性が出る。

### ③ YouTube（余力があれば）
- ショートをTikTokと使い回し。概要欄にアフィリエイトリンク（もしもアフィリエイト等はYouTube掲載可の案件が多い）。

## 4. 差別化（なぜあなたから買うのか）

ドッグフードアフィリエイトは「報酬が高い商品を絶賛するだけのランキングサイト」が乱立して読者に見抜かれている。逆張りで信頼を取る:

1. **実体験を出す**: 自分の犬に実際に与えた写真・動画・食いつきの変化・便の状態まで載せる。AI生成の一般論記事との決定的な差になる。
2. **デメリットを書く**: 「モグワンが合わなかった犬の特徴」のような正直コンテンツはCVRが高い。
3. **専門性の担保**: 愛玩動物飼養管理士（通信で取得可、約3万円）などの資格をプロフィールに載せると信頼度が大きく上がる。
4. **一次データ**: 「うちの犬の年間医療費を全公開」のような実データ記事は保険案件と相性が良く、被リンクも集まる。

## 5. ロードマップ（12ヶ月）

| 期間 | やること | 目標 |
| --- | --- | --- |
| 1〜2ヶ月目 | ASP登録・ブログ開設・SNS開始。収益記事5本+集客記事10本 | 収益0円でOK（仕込み期） |
| 3〜4ヶ月目 | SNS週4投稿を継続、記事計30本。ストーリーズ/プロフからブログ誘導開始 | 初成果発生（月3,000〜1万円） |
| 5〜7ヶ月目 | 当たった動画・記事の型を量産。ペット保険記事を強化 | 月2〜3万円 |
| 8〜10ヶ月目 | 検索順位が付いた記事をリライトしてCVR改善。案件の特単（特別単価）交渉 | 月5〜7万円 |
| 11〜12ヶ月目 | フォロワー1万人規模、記事60本超。成約導線の最適化 | **月10万円** |

※ 成約20〜30件/月に必要なブログアクセスの目安は月2〜3万PV（CVR 0.1〜0.15%換算）。SNS経由の指名流入はCVRが数倍高いので、SNSが育つほど必要PVは減る。

## 6. 法令・規約の注意（必読）

- **ステマ規制（景品表示法、2023年10月〜）**: アフィリエイトリンクを含む記事・投稿には「PR」「広告」表記が必須。SNS投稿にも #PR を付ける。
- **薬機法・健康増進法**: 「このフードでアレルギーが治る」「涙やけが治る」等の効能断定はNG。「うちの犬の場合は〜だった」の体験談形式に留める。
- **各ASP・Amazonの規約**: リンクの貼り方（メルマガ・LINE配布可否など）は案件ごとに確認。
- 誇大な比較で他社を貶める表現は景表法の優良誤認リスク。

## 8. よくある失敗

- ランキング記事だけ量産して実体験ゼロ → 検索でもSNSでも埋もれる。
- 低単価物販だけで頑張る → 件数が積めても月1万円で頭打ち。
- 3ヶ月で成果が出ずやめる → SEOもSNSも複利型。5〜7ヶ月目からが本番。
- 1つのASPしか使わない → 同一案件で単価が1.5倍違うことがある。
