# Google広告営業 × AI活用プレイブック

対象: Google広告の営業担当。ミッションは (1) 広告配信費用の増加、(2) Google推奨プロダクトの導入促進。
制約: 使えるAIツールは **Googleのもののみ**(Gemini / Gemini for Workspace / NotebookLM / GAS + Gemini API / Colab / Looker Studio / AppSheet / Vertex AI など)。

営業プロセスの順(Planning → 商談準備 → Pitch → コミュニケーション → 効果検証 → プロダクト導入)に、すぐ使える小ネタから自動化の仕込みまで並べています。各項目に【手軽さ】(◎=今日から / ○=数時間の仕込み / △=数日の開発)を付けています。

---

## 0. 使える道具の整理

| ツール | 得意なこと |
|---|---|
| Gemini アプリ(Deep Research / Gems / Canvas) | 調査、壁打ち、カスタムアシスタント化 |
| Gemini in Gmail / Docs / Sheets / Slides / Meet | メール下書き、資料ドラフト、表分析、議事録 |
| NotebookLM | 顧客資料・社内事例を「根拠付きで」Q&A、音声概要 |
| GAS (Apps Script) + Gemini API | Gmail/Calendar/Sheets/Slides を絡めた自動化の本命 |
| Google Ads Scripts | アカウントデータの定期取得・自動レポート |
| Looker Studio | ダッシュボード、顧客共有用レポート |
| Colab (+ Gemini) | 大きめのデータ分析、検索語句クラスタリング等 |
| Imagen / Veo / Google Vids | クリエイティブのモックアップ、提案動画 |
| AppSheet | パイプライン管理などの簡易アプリ |

## 1. Planning(アカウントプラン・優先順位付け)

### 1-1. Deep Research で顧客・業界調査を自動化 【◎】
- 「○○社の事業構造、直近の決算ハイライト、マーケティング動向、競合をまとめて」と投げるだけで、リンク付きの調査レポートが出る。
- 業界単位でも有効:「日本のD2Cコスメ市場の広告出稿トレンドと季節性」→ 予算増額提案の背景資料に。

### 1-2. NotebookLM に「顧客ノートブック」を作る 【◎】
- 顧客ごとにノートブックを作り、IR資料・中期経営計画・過去の提案書・議事録を投入。
- 「この会社の経営課題のうち、広告投資で解決できるものは?」「昨年の提案で刺さらなかった論点は?」と根拠付きで聞ける。
- 音声概要(Audio Overview)で通勤中に顧客理解のインプットも可能。

### 1-3. ポートフォリオの伸びしろスコアリング 【○】
- 担当アカウント一覧(Sheets)に、予算・業種・導入済みプロダクト・前年比などを整備。
- Gemini in Sheets に「増額余地が大きい順にスコアリングして理由も書いて」と依頼。
- 発展形: GAS + Gemini API で毎週自動更新し、上位5社をChat/メールに通知。

### 1-4. 顧客ニュース週次ダイジェスト 【○/△・GAS実装向き】
- Sheetsの顧客リストをGASで回し、Gemini API(Google Search grounding付き)で各社の直近ニュース(新商品、出店、決算、キャンペーン)を要約。
- 毎週月曜朝に自分宛メールで「今週話しかけるネタ」が届く状態にする。**増額提案のきっかけ検知機**として機能する。

### 1-5. 季節性・需要予測を提案の根拠に 【◎】
- Google Trends のデータをSheetsに貼り、Geminiで「この業種の需要ピークと、その2ヶ月前から予算を積むべき理由」を文章化。
- Performance Planner の出力を「顧客の言葉のストーリー」に翻訳させる。

### 1-6. 競合出稿の分析 【◎】
- Ads Transparency Center で競合の出稿クリエイティブを確認 → スクショをGeminiに読ませ「競合の訴求軸の分類と、この顧客が取るべき差別化」を整理させる。

## 2. 商談準備(Prospecting / Pre-meeting)

### 2-1. 商談前ブリーフィングの自動生成 【△・GAS実装の一押し】
- GASでCalendarを毎朝スキャン → 外部参加者のドメインから会社を特定 → Gemini APIで「会社概要 / 直近ニュース / 想定される広告課題 / 提案できるGoogleプロダクト / 想定質問」を生成 → 商談の朝にメールで届く。
- 1商談あたり15〜30分の準備時間を毎回節約できる。

### 2-2. 「商談準備Gem」を作る 【◎】
- Gemini の Gems に、自分の営業スタイル・扱うプロダクト(PMax、Demand Gen、部分一致+スマート自動入札 など)・よく使う論法を仕込んだカスタムアシスタントを作成。
- 「アパレルEC、月額300万円、指名検索中心」と入れるだけで、課題仮説→推奨プロダクト→トークの流れが出るようにする。

### 2-3. 反論処理のロールプレイ 【◎】
- Geminiに「あなたは広告予算に懐疓的なEC企業のマーケ部長。私のPMax提案に厳しく反論して」と演じさせ、模擬商談。
- 「PMaxはブラックボックスだ」「部分一致は無駄クリックが増える」など定番の反論への切り返しを事前に鍛えられる。

### 2-4. 想定問答集(FAQ)の自動生成 【◎】
- 提案書ドラフトをGeminiに読ませ「この提案に対して顧客のCFO/マーケ責任者/現場担当それぞれが聞きそうな質問と模範回答を10個ずつ」と依頼。

### 2-5. 社内事例ライブラリのNotebookLM化 【○】
- 社内で共有されている成功事例・ケーススタディをNotebookLMに集約。
- 商談前に「食品ECでDemand Genを入れてROASが改善した事例は?」と聞けば、引用付きで即答 → そのままピッチに使える。

## 3. Pitch(提案資料・プレゼン)

### 3-1. 提案書ドラフトを Gemini in Slides / Docs で 【◎】
- アウトライン(課題→解決策→期待効果→次のステップ)をGeminiに書かせてからSlidesへ。ゼロから作らない。
- 「この提案をエグゼクティブ向けに1枚に要約して」でサマリースライドも生成。

### 3-2. 提案書の一括パーソナライズ 【△・GAS実装向き】
- マスターのSlidesテンプレート + Sheetsの顧客データ(社名、実績数値、推奨プロダクト、期待効果)を用意。
- GASで顧客ごとに差し込み生成し、説明文パートはGemini APIで「その顧客の業種の言葉」に書き換え。
- 10社分の提案書カスタマイズが数分で終わる。

### 3-3. 推奨プロダクトの「翻訳」 【◎】
- 「PMaxを、ITに詳しくない老舗和菓子屋の社長に、店舗の売上の言葉で説明して」のように、**同じプロダクトを顧客ごとの語彙で説明し直す**のはGeminiの最も得意な仕事。
- ミッション2(プロダクト導入)に直結。断られる理由の多くは「価値が自分事化されていない」ことなので、ここをAIで潰す。

### 3-4. クリエイティブのモックアップで「見せる」提案 【◎】
- Imagen / Veo で「御社の商品ならこんなDemand Gen向け画像・動画が作れます」のモックを生成して見せる。
- 「クリエイティブを作るリソースがない」という導入障壁への直接の回答になる。Google広告側のAI生成アセット機能への橋渡しにも。

### 3-5. パーソナライズ提案動画 【○】
- Google Vids で、顧客名入りの短い提案動画を作成。多忙な決裁者に「3分で見られる提案」として送る。

### 3-6. 数値シミュレーションのストーリー化 【◎】
- Performance Planner やキーワードプランナーの出力をGeminiに渡し、「予算を+30%した場合のシナリオを、リスクと機会の両面で顧客向けの文章に」と依頼。

## 4. メール・コミュニケーション効率化

### 4-1. Gmail の Help me write + トーンGem 【◎】
- 日常の返信はHelp me writeで下書き→自分のトーンに調整。
- 自分の過去メールの良い例をGemsに仕込み、「自分らしい文体」で生成させると手直しが激減。

### 4-2. パーソナライズ営業メールの一括ドラフト生成 【△・GAS実装の一押し】
- Sheetsに顧客リスト(社名、担当者、業種、直近の話題、提案したいプロダクト)を用意。
- GAS + Gemini API で1社ずつ「その会社専用の」メール本文を生成し、**送信ではなくGmailの下書きとして保存**。
- 自分は下書きを確認・微修正して送るだけ。パーソナライズの質を落とさず量を10倍にできる。

### 4-3. 未返信フォローアップの自動検知 【○】
- GASで「自分が送って○日返信がないスレッド」を抽出し、Gemini APIでフォローアップ文面を生成して下書き作成。
- 「追いかけ漏れ」というパイプラインの穴を機械的に塞ぐ。

### 4-4. 受信トレイの自動トリアージ 【○】
- GASで新着メールをGemini APIに分類させる(緊急対応 / 数値照会 / 日程調整 / 情報共有)→ ラベル付け+緊急のみChat通知。

### 4-5. 商談後お礼メール+議事録の自動ドラフト 【○】
- Gemini in Meet の自動メモ(Take notes for me)→ 終了後にGASが要約を取得 → お礼+決定事項+ネクストステップのメールドラフトを生成。
- 商談後1時間以内のフォローが habit化できる。

## 5. 商談中・商談後

### 5-1. Gemini in Meet で議事録・アクションアイテム自動化 【◎】
- メモ取りから解放され、商談中は会話に集中。要約とTo-Doが自動で残る。

### 5-2. 議事録 → CRM/管理シートへの構造化入力 【○】
- 議事録テキストをGemini APIで構造化(BANT: 予算/決裁者/ニーズ/時期、次アクション、温度感)し、Sheetsのパイプライン管理表へ自動追記。
- 「CRM入力が面倒で後回し」問題の解消。

### 5-3. セルフコーチング 【◎】
- 商談メモや(許可の取れた)文字起こしをGeminiに渡し、「話しすぎていないか」「顧客の課題を深掘りする質問ができたか」「クロージングの一歩が明確だったか」をレビューさせる。

### 5-4. Next Best Action の提案 【◎】
- 「この商談メモを読んで、受注確度を上げるために次の1週間でやるべきこと3つを優先度順に」と聞く。パイプラインレビュー前の壁打ちに。

## 6. 効果検証・レポーティング(増額提案の弾込め)

### 6-1. 週次パフォーマンスサマリの自動生成 【△・GAS/Ads Script実装の一押し】
- Google Ads Scripts でアカウントの主要指標(費用、CV、CPA、ROAS、インプレッションシェア損失率)を毎週Sheetsに出力。
- Gemini APIで「先週比の変化点、その推定要因、来週の推奨アクション」を自然言語で生成し、自分(または顧客)宛にメール。
- **「インプレッションシェア損失(予算)」が出ているアカウントは、そのまま増額提案の根拠になる** — これを自動で拾う仕組みは売上ミッションに直結。

### 6-2. 異常検知アラート 【○】
- 日次でCPA/費用の急変をAds Scriptで検知 → Geminiが「顧客に説明できる文章」で要因仮説を添えてChatに通知。
- 顧客から聞かれる前にこちらから連絡できる=信頼貯金。

### 6-3. Looker Studio ダッシュボード+AI解説 【○】
- 顧客共有用のLooker Studioを整備し、月次ではそのデータをGeminiに渡して「経営層向けエグゼクティブサマリ」を生成。
- 数字を見せるだけでなく「so what」を必ず添える。

### 6-4. 検索語句レポートのクラスタリング 【○】
- 検索語句レポートをSheets/Colabに落とし、Geminiで意図別にクラスタリング。
- 「新規キーワード候補」「除外候補」「部分一致で拾えている良質なクエリ」を仕分け → **部分一致+スマート自動入札の推奨トークの実データ根拠**になる。

### 6-5. 広告文(RSA)アセットの改善提案 【◎】
- 評価の低いアセットと商品情報をGeminiに渡し、改善案を15本生成 → 顧客に「来月これをテストしましょう」と提案。
- クリエイティブ改善の提案は追加費用ゼロで成果を上げる話なので、信頼構築→その後の増額につながる。

### 6-6. QBR(四半期レビュー)資料の半自動生成 【△】
- 実績データ(Sheets)+ 期初の目標 + 議事録をGeminiに渡し、QBRのストーリーライン(達成/未達の要因→学び→来期の投資提案)をドラフト → Slidesへ。
- QBRの締めを常に「来期の推奨プロダクト+予算案」にする型をテンプレ化。

### 6-7. 「なぜ悪化したか」説明ドラフト 【◎】
- パフォーマンス悪化時、指標の変化と市場要因(季節、競合、検索需要)をGeminiに渡して説明資料の初稿を作る。守りの対応を速くして解約・減額を防ぐ。

## 7. プロダクト導入促進(ミッション2に特化)

### 7-1. 導入ギャップ分析マトリクス 【○】
- Sheetsで「顧客 × 推奨プロダクト(PMax / Demand Gen / 部分一致 / 目標ROAS / 拡張CV / GA4連携…)」の導入状況マトリクスを管理。
- Gemini in Sheets で「未導入の中で、この顧客の業種・目標に最もインパクトが大きいものはどれか、優先度と提案トーク付きで」と分析。
- GAS化すれば「今月の導入提案ターゲットリスト」が自動で出る。

### 7-2. 導入障壁ごとの切り返し集 【◎】
- プロダクトごとに「よくある導入拒否理由 → データでの反証 → 小さく始める提案(実験機能、予算の10%だけ等)」をGeminiと作り込み、Gemsに保存してチームで共有。

### 7-3. 「AIを使っている営業」自体がデモになる 【◎】
- 商談準備の速さ、パーソナライズされた資料、Imagenのモックなどを見せること自体が「GoogleのAIはここまでできる」という無言のピッチになる。AI系プロダクト(AI生成アセット、PMaxのAI機能)への心理的抵抗を下げる。

### 7-4. 顧客向けミニ勉強会コンテンツの量産 【◎】
- 「Demand Genとは」をNotebookLMに公式ヘルプを入れて顧客向け資料化、音声概要を顧客の予習用に渡す、など教育コンテンツをAIで量産。

- **パイプライン健全性チェック** 【○】: Sheetsのパイプラインを毎週Geminiが査読し、「長く動いていない案件」「次アクション未設定の案件」を指摘。

## 10. 注意事項

- **顧客データの扱い**: 顧客の機密データをどのAIサービスに入れてよいかは社内ポリシーに従うこと(Workspace統合のGemini/NotebookLM Enterpriseはデータがモデル学習に使われない設計だが、個人のAPIキー利用時はデータ取り扱い区分の確認を)。
- **送信前レビュー**: メール・提案書は必ず人間が最終確認する運用にする(自動化は「下書きまで」が安全)。
- **数値の検証**: Geminiが生成した数値・事例は必ず一次ソースで確認してから顧客に提示する。
