# 全体まとめ: Scalable × Deep Dive の2軸 × 提案プロセス

これまでのアイデアを、提案プロセスの5段階 × 2つのアプローチで整理した総括版。
詳細・プロンプト例は `ai-sales-playbook.md` / `proposal-engagement-deep-dive.md` を参照。

## 2軸の定義

| | **Scalable(仕組みで広く)** | **Deep Dive(重点顧客に深く)** |
|---|---|---|
| 対象 | 担当する全顧客(特にロングテール) | 大口・戦略顧客・増額余地の大きい顧客 |
| 手段 | GAS + Gemini API / Ads Scripts による**自動化** | Gemini / Deep Research / NotebookLM を**対話的に**使う |
| 成果物 | 毎週自動で届くダイジェスト・下書き・アラート | 1社ごとに作り込んだ仮説・提案書・体験 |
| 人の役割 | 確認して送る/対応するだけ | AIと壁打ちしながら質を作り込む |
| 効果 | 接点の「量」とカバレッジ | 提案の「質」と受注単価 |

運用の考え方: **全顧客にScalableの網を張り、そこで見つかったシグナル(増額機会・温度感の高さ)を起点に、Deep Diveに切り替える。** 2軸は排他ではなく漏斗の関係。

## プロセス別マトリクス

### 1. Planning(アカウント分析・優先順位付け)

| Scalable | Deep Dive |
|---|---|
| **顧客ニュース週次ダイジェスト**: 全顧客のニュースをGASで自動収集・要約し月曜朝に配信 | **Deep Research 顧客調査**: 決算・競合・市場を1社を数十分で徹底調査 |
| **伸びしろ自動スコアリング**: 顧客リストを毎週スコアリングし「今月攻める上位5社」を通知 | **NotebookLM顧客ノートブック**: IR資料・過去提案・議事録を入れて根拠付きQ&A、アカウントプラン作成 |
| **IS損失(予算)の自動検知**: Ads Scriptsで機会損失アカウントを毎週リストアップ = 増額ターゲットの自動発見 | **競合出稿分析**: Ads Transparency Centerの出稿をGeminiで分析し差別化ポイントを設計 |

### 2. 商談準備

| Scalable | Deep Dive |
|---|---|
| **商談前ブリーフィング自動生成**: Calendarをスキャンし、全商談に「会社概要・ニュース・想定課題・推奨プロダクト」を自動配信 | **課題仮説ジェネレーター**: 顧客情報から課題仮説3つ+検証質問を作り込む |
| **社内事例のNotebookLM化**: 事例集を一度整備すれば全商談で「同業種の成功事例」を即引用 | **反論処理ロールプレイ**: Geminiに厳しい決裁者を演じさせて模擬商談 |
| | **想定問答集**: CFO/マーケ責任者/現場それぞれの想定質問と模範回答を準備 |

### 3. 提案作成(Pitch)

| Scalable | Deep Dive |
|---|---|
| **提案書一括パーソナライズ**: マスターテンプレ+Sheets顧客データ→GASで10社分を自動差し込み生成 | **翻訳レイヤー**: 決算資料から顧客の「公式の言葉・KPI」を抽出し、提案をその語彙で書き直す |
| **推奨プロダクト説明の業種別テンプレ**: 「PMaxを○○業向けに」の説明バリエーションを事前量産 | **松竹梅3案構成**: 増額をYes/Noでなく「どれにするか」の議論に変える設計 |
| **役職別の書き分け**: 経営者3行/マーケ半ページ/運用者手順書、を機械的に生成 | **レッドチームGem**: 「予算に厳しい役員」に提案書を事前レビューさせ弱点を潰す |
| | **Imagen/Veoクリエイティブモック**: 「御社ならこんな広告が作れる」を見せる。制作リソース不足の障壁も解消 |

### 4. コミュニケーション/エンゲージメント

| Scalable | Deep Dive |
|---|---|
| **エンゲージメント・エンジン(本命)**: ニュース/パフォーマンス/季節の3シグナル→「連絡する理由+文面下書き」を毎週自動供給 | **商談後60分フォロー**: Meet議事録→お礼+決定事項+「拾い残しトピック」抽出で次回商談を仕込む |
| **パーソナライズメール工場**: 顧客リスト×Gemini APIで各社専用文面をGmail下書きに一括生成 | **NotebookLMノートブック共有・音声概要**: 提案一式を顧客が質問しながら理解できる形で渡す |
| **未返信フォロー自動検知**: 放置スレッドを検出しフォロー文面を下書き | **Google Vidsパーソナライズ動画**: 決裁者向け「3分で見られる提案」 |
| **月次インサイトレター**: 業種ごとに1本作って同業種顧客全員に展開(売り込まない接点) | |
| **休眠顧客の再活性化**: 45日無接点を検知し再エンゲージ文面を生成 | |

### 5. 効果検証・フォロー(増額/プロダクト導入)

| Scalable | Deep Dive |
|---|---|
| **週次パフォーマンスサマリ自動生成**: 全アカウントの変化点+推奨アクションを自然言語で自動配信 | **QBR資料の作り込み**: 実績+目標+議事録から「達成要因→学び→来期投資提案」のストーリーを構築 |
| **異常検知アラート**: CPA/費用急変を検知し「顧客に説明できる文章」付きで通知 → 先回り連絡 | **So What変換**: IS損失→機会損失額への換算など、数字を経営の言葉に翻訳した増額ストーリー |
| **導入ギャップ分析**: 顧客×推奨プロダクトのマトリクスから「今月の導入提案リスト」を自動生成 | **検索語句クラスタリング**: 部分一致+スマート自動入札を推す実データ根拠を作る |
| **RSAアセット改善案の量産**: 低評価アセットの改善案を自動生成 | **悪化時の説明資料作り込み**: 要因分解と挽回プランで減額・解約を防ぐ |

## ミッションとの対応

- **売上(配信費用増)**: Scalable側の「IS損失自動検知」「エンゲージメント・エンジン」で増額機会を漏らさず発見 → Deep Dive側の「松竹梅3案」「So What変換」で決めきる。
- **推奨プロダクト導入**: Scalable側の「導入ギャップ分析」でターゲットを自動抽出 → Deep Dive側の「翻訳レイヤー」「クリエイティブモック」で導入障壁(自分事化不足・制作リソース不足)を潰す。

## 実装優先順位(コードを書くもの = Scalable側)

1. パーソナライズメール工場(GAS小・すぐ効果が見える)
2. 商談前ブリーフィング自動生成(GAS小)
3. 週次サマリ+IS損失検知(Ads Scripts + Gemini)
4. エンゲージメント・エンジン(1の部品を再利用して構築)

Deep Dive側は基本ノーコード: 今日からGems登録(レッドチームGem、仮説ジェネレーター、翻訳レイヤー)で始められる。
