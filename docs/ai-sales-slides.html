Planning — 誰に・なぜ・いつ攻めるか

Scalable
  • IS損失(予算)の自動検知Ads Scriptsで機会損失アカウントを毎週リストアップ = 増額ターゲットの自動発見
  • 顧客ニュース週次ダイジェスト全顧客の新商品・出店・決算をGASが収集、月曜朝に「話しかけるネタ」が届く
  • 伸びしろ自動スコアリング顧客リストを毎週採点し「今月攻める上位5社」を通知

使う道具: GAS + Gemini API Ads Scripts Sheets

Deep Dive
  • NotebookLM 顧客ノートブックIR資料・過去提案・議事録を投入し、根拠付きでアカウントプランを構築
  • Deep Research 徹底調査決算・競合・市場動向を1社数十分でレポート化
  • 競合出稿分析Ads Transparency Centerの出稿をGeminiで分析し、差別化ポイントを設計

使う道具: Deep Research NotebookLM Gemini

1. Planning2. 商談準備3. 提案作成4. エンゲージメント5. 効果検証

商談準備 — 準備の速さと深さを両立する

Scalable
  • 商談前ブリーフィング自動生成Calendarをスキャンし、全商談に「会社概要・ニュース・想定課題・推奨プロダクト」を朝に自動配信。毎回15〜30分の準備を節約
  • 社内事例のNotebookLM化事例集を一度整備すれば、全商談で「同業種の成功事例」を引用付きで即答

使う道具: GAS + Calendar + Gemini API NotebookLM

Deep Dive
  • 課題仮説ジェネレーター顧客情報から「課題仮説3つ+根拠+検証質問」を生成。プロダクト起点でなく課題起点の商談に
  • 反論処理ロールプレイGeminiに厳しい決裁者を演じさせて模擬商談。「PMaxはブラックボックス」等の定番反論を事前に鍛える
  • 役職別の想定問答集CFO/マーケ責任者/現場、それぞれの想定質問と模範回答を準備

使う道具: Gemini (Gems)

提案作成 — 「Googleの話」を「顧客のビジネスの話」に

Scalable
  • 提案書の一括パーソナライズマスターテンプレ+Sheets顧客データ → GASで10社分を自動差し込み生成
  • 業種別プロダクト説明の量産「PMaxを◯◯業の言葉で」の説明バリエーションを事前に量産して使い回す
  • 役職別の書き分け経営者3行 / マーケ半ページ / 運用者手順書、を機械的に生成

使う道具: GAS + Slides API + Gemini API

Deep Dive
  • レッドチームGem「予算に厳しい役員」を演じるGemに、提出前の提案書を叩かせて弱点を潰す
  • 翻訳レイヤー決算資料から顧客の「公式の言葉・KPI」を抽出し、提案をその語彙で書き直す
  • 松竹梅の3案構成増額提案をYes/Noでなく「どれにするか」の議論に変える
  • Imagen / Veo クリエイティブモック「御社ならこんな広告が作れる」を見せる。制作リソース不足の導入障壁も解消

使う道具: Gemini (Gems) Imagen / Veo Google Vids

エンゲージメント — 「連絡する理由」を絶やさない

Scalable
  • エンゲージメント・エンジン(本命)ニュース / パフォーマンス変化 / 季節の3シグナル → 「連絡する理由+文面下書き」を毎週自動供給
  • パーソナライズメール工場顧客リスト × Gemini APIで各社専用の文面をGmail下書きに一括生成。質を保って量を10倍に
  • 未返信検知・休眠再活性化放置スレッドと45日無接点の顧客を検知し、再エンゲージ文面を下書き
  • 月次インサイトレター業種ごとに1本、売り込まない「業界の話」を作り同業種顧客全員に展開

使う道具: GAS + Gmail + Gemini API Google Trends

Deep Dive
  • 商談後60分フォローMeet議事録 → お礼+決定事項+「拾い残しトピック」を抽出し、次回商談を仕込む
  • NotebookLM共有・音声概要提案一式をノートブックで渡し、顧客が質問しながら理解できる形に。予習用ポッドキャストも
  • Google Vids パーソナライズ動画多忙な決裁者向けの「3分で見られる提案」

使う道具: Gemini in Meet NotebookLM Google Vids

効果検証 — 検証結果を次の増額・導入の弾にする

Scalable
  • 週次パフォーマンスサマリ自動生成全アカウントの変化点+推奨アクションを自然言語で自動配信
  • 異常検知アラートCPA/費用の急変を「顧客に説明できる文章」付きで通知 → 聞かれる前に先回り連絡
  • 導入ギャップ分析顧客×推奨プロダクトのマトリクスから「今月の導入提案リスト」を自動生成
  • RSAアセット改善案の量産低評価アセットの改善案を自動生成し「来月のテスト」として提案

使う道具: Ads Scripts + Gemini API Looker Studio

Deep Dive
  • So What変換IS損失 → 「機会損失額」への換算など、数字を経営の言葉に翻訳した増額ストーリー
  • QBRストーリーの作り込み実績+目標+議事録から「達成要因 → 学び → 来期投資提案」を構築
  • 検索語句クラスタリング部分一致+スマート自動入札を推すための実データ根拠を作る
  • 悪化時の説明資料要因分解と挽回プランを速く出し、減額・解約を防ぐ

使う道具: Gemini Colab Sheets
