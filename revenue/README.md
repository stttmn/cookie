# 💰 月5万円 収益チーム — クックノート

「クックノート」（料理レシピ・献立・買い物リストアプリ）を収益化し、**月間売上 50,000円** を目指すためのAIエージェントチームと運用プランです。

## 正直な前提
このチームは **企画・制作・SEO・実装・分析** を自動で回す実働部隊です。
現金の入金・広告審査の申請・SNSやストアへの公開・決済連携といった **最終操作は人間が行う** 設計にしています（🧑マークのタスク）。AIが「勝手に現金を稼ぐ」ものではなく、「5万円を稼げる仕組みを高速で作り上げる」チームです。

## チーム構成（`.claude/agents/`）

| エージェント | 役割 |
| --- | --- |
| 🧭 **growth-lead** | 統括・PM。戦略、KPI管理、タスク配分、優先順位判断 |
| 🔍 **seo-specialist** | キーワード調査・検索意図分析・内部SEO |
| ✍️ **content-writer** | SEO記事・アプリ内コンテンツ・レシピ集の制作 |
| 💵 **monetization** | 広告/アフィリ/有料プラン/デジタル商品の売上最適化 |
| 🛠️ **product-dev** | アプリ本体への機能実装（有料機能・導線・計測） |
| 📊 **analytics** | 数値分析・ボトルネック特定・効果検証 |

各エージェントはClaude Codeのサブエージェントとして、`> use the growth-lead agent to ...` のように呼び出せます。まず **growth-lead** に号令をかけ、そこから他のエージェントへ展開する運用です。

## 収益モデル（4本柱・保守的な積み上げ）

| 収益源 | 月額(想定) |
| --- | --- |
| 有料プラン（月480円 × 60人）※主軸 | 28,800円 |
| 広告（30,000PV × RPM400円） | 12,000円 |
| アフィリエイト（楽天/Amazon） | 6,750円 |
| デジタル商品（note/Kindleレシピ集） | 5,000円 |
| **合計** | **≈ 52,550円** |

詳細と感度分析 → [`revenue-model.md`](./revenue-model.md)

## 使い方（クイックスタート）
1. `revenue/30-day-plan.md` を開き、今週のタスクを確認。
2. Claude Code で **growth-lead** を呼ぶ:
   > growth-lead エージェントで、今週の最優先タスクを3つに絞って各担当への指示書を作って
3. 指示に沿って各エージェント（seo-specialist → content-writer → monetization → product-dev）を回す。
4. 週末に **analytics** で実績を集計し、`progress-log.md` を更新。

## 現実的な期待値
- 30日: 最初の売上（数百〜数千円）+ 資産（記事・計測・課金の器）
- 3〜6か月: 記事数と有料会員を積み上げて **月5万円** へ

> 誇大な収益予測はしません。数字は常に保守側で見積もり、実績で更新します。
