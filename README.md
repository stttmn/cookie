# 🍳 クックノート (cookie)

SNS・ウェブサイトのレシピを保存して、献立提案から買い物メモまでを1つで完結できる料理アプリです。
ビルド不要の静的サイト（HTML/CSS/JavaScript のみ）で、データはブラウザの localStorage に保存されます。

## 機能

- **📥 SNSレシピの文字起こし** — YouTube・Instagram・TikTok の投稿URLを認識し、概要欄・キャプションを貼り付けると「材料」「作り方」「人数」「タグ」に自動で構造化します。
- **🌐 ウェブサイトのインポート** — レシピサイトのURLから構造化データ（schema.org/Recipe の JSON-LD）や本文を解析してレシピを自動抽出します。
- **📖 レシピの保存** — カテゴリ（主菜/副菜/汁物/主食）・ジャンル（和洋中）・タグ付きで保存。検索・編集・人数に応じた分量の自動換算に対応。
- **🍽️ 献立の提案** — 人数・カロリー嗜好（控えめ/標準/しっかり/カスタム）・ジャンルの好み・肉/魚/野菜のこだわりに合わせて、保存済みレシピから主菜+副菜+汁物の組み合わせを提案。食材ベースのカロリー推定DB（約120食材）内蔵。
- **🛒 買い物メモ** — 献立やレシピから材料を人数分に換算して自動集計。同じ食材はまとめて売り場カテゴリ別に整理。チェックリスト・テキストコピーに対応。

## 起動方法

```bash
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（タブ・モーダル） |
| `styles.css` | スタイル |
| `data.js` | 食材カロリーDB・カテゴリ辞書・サンプルレシピ |
| `parser.js` | レシピ文字起こしエンジン（テキスト/JSON-LD解析・分量計算・カロリー推定） |
| `app.js` | アプリ本体（保存・献立提案・買い物リスト） |

初回起動時に12件のサンプルレシピが登録されます（削除可）。
