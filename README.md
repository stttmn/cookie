# 🔧 カスタムガレージ

いろんな車の外装を自由にアレンジして遊べるサイトです。
ビルド不要の静的サイト（HTML/CSS/JavaScript のみ）で、保存データはブラウザの localStorage に置かれます。

## 遊べること

- **🚘 車種えらび** — セダン / スポーツ / SUV / 軽ワゴン / ピックアップ / バン の6車種（すべてSVG手描き）
- **🎨 ボディカラー** — プリセット12色＋カラーピッカーで自由な色。仕上げはソリッド / メタリック / マット / パール
- **🏷️ デカール** — ストライプ・サイドライン・ファイア・水玉・サンダー・ゼッケン（番号ランダム）。デカール色も変更可
- **🛞 ホイール** — スポーク / メッシュ / ディッシュ / スター / 鉄チン ＋ リム色
- **🔩 パーツ & セッティング** — スポイラー、ルーフボックス、ネオン（アンダーグロウ）、窓のスモーク、車高調整（シャコタン⇄リフトアップ）
- **🌆 背景ステージ** — シティ / 夕焼け / 山道 / ナイト / ビーチ / ガレージ
- **🏁 はしる！** — ホイールが回り背景が流れる走行モード。ナイト×走行でヘッドライト点灯
- **🎰 おまかせガチャ** — 全項目ランダムの一台が出てくる。「愛車ネーム」も自動命名（例:「蒼空の韋駄天・サンダー号」）
- **💾 マイガレージ** — 最大24台までブラウザに保存してコレクション。ワンクリックでステージに呼び戻し
- **📸 PNG保存** — 今の一台を 1120×600 のPNG画像としてダウンロード

## 起動方法

```bash
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（ステージ・コントロールパネル・ギャラリー） |
| `styles.css` | スタイル（ガレージ風ダークテーマ） |
| `cars.js` | 車種・ホイール・デカールのSVG形状定義 |
| `scenes.js` | 背景ステージのSVG定義 |
| `app.js` | アプリ本体（状態管理・SVG合成・ガチャ・保存・PNG書き出し） |
