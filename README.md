# 🔧 カスタムガレージ

**本物の車の写真**を検索してえらび、外装を自由にアレンジして遊べるサイトです。
ビルド不要の静的サイト（HTML/CSS/JavaScript のみ）。車の写真はフリー百科事典の画像庫
[Wikimedia Commons](https://commons.wikimedia.org/) からブラウザが直接取得します。

## 遊べること

- **🚘 車えらび** — 好きな車名で検索（例: Nissan GT-R / Toyota Supra）。GT-R・スープラ・RX-7 などのクイックチップ付き。切り抜き（透過PNG）画像を選ぶと全機能が使える
- **🎨 色替え** — プリセット12色＋カラーピッカー。写真の陰影を保ったまま塗り替え（輝度マスクでタイヤ・窓は塗らない）。色のこさ調整、グロス／マット質感
- **🏷️ デカール** — ストライプ・サイドライン・ファイア・水玉・サンダー・ゼッケン（番号ランダム）。車体の不透明部分にだけ貼られる
- **🔩 セッティング** — ネオン（アンダーグロウ＋オーラ）、左右反転、大きさ・上下位置の調整
- **🌆 背景ステージ** — シティ / 夕焼け / 山道 / ナイト / ビーチ / ガレージ
- **🏁 はしる！** — 背景が流れて車が揺れる走行モード
- **🎰 おまかせガチャ** — 車も色もデカールも全部ランダム。「愛車ネーム」を自動命名
- **💾 マイガレージ** — 最大24台までブラウザに保存（サムネイル付き）
- **📸 PNG保存** — 画像クレジット入りの 1120×600 PNG をダウンロード

## 起動方法

```bash
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

`?mock=1` を付けるとローカルのテスト画像（`test-fixtures/`、リポジトリには含まれない）で
オフライン動作確認ができます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（検索・ステージ・コントロール・ギャラリー） |
| `styles.css` | スタイル（ガレージ風ダークテーマ） |
| `commons.js` | Wikimedia Commons 画像検索クライアント |
| `engine.js` | canvas合成エンジン（解析・色替え・デカール・書き出し） |
| `scenes.js` | 背景ステージのSVG定義 |
| `app.js` | アプリ本体（状態管理・UI・ガチャ・保存） |

## 画像のライセンス

車の写真は Wikimedia Commons のフリーライセンス画像（CC BY / CC BY-SA / パブリックドメイン等）を
実行時に取得して表示します。各画像の作者・ライセンスはステージ下のリンクから確認でき、
PNG書き出し時にはクレジットが画像内に焼き込まれます。
